HOW TO TEST
1. On Windows, double-click START_TEST_SERVER.bat.
2. The website opens at http://localhost:8000.
3. Test products, colour/size switching, cart, checkout methods, map directions and WhatsApp order generation.
4. Alternative: open the folder in VS Code and use Live Server, or run: python -m http.server 8000

DEPLOYMENT / DOMAIN
Upload every file and the complete assets folder to the selected host without changing the folder structure. Once the final domain is purchased, point the domain to the host and add the exact live domain as the canonical URL and sitemap base URL.

IMPORTANT
- Current-location access works after deployment on HTTPS or while using localhost.
- WhatsApp does not send automatically; the customer reviews and sends the generated message.
